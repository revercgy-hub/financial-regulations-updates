# 金融监管知识库 Android 联网同步版

本仓库为金融监管知识查询 APP 提供在线更新服务。

- 制度库：人民银行、国家金融监督管理总局和国家外汇管理局，共 2,021 篇。
- 案例库：财政部、证监会、审计署、中央纪委国家监委，共 2,810 条。
- `android-app/`：原生 Android APP，首次启动联网下载知识库，后续按版本自动同步。
- `deployment/`：案例刷新、知识库更新包构建、版本清单和发布工具。
- GitHub Releases：存放知识库压缩包与可安装 APK。

APP 使用 `deployment/update/latest.json` 检查版本，下载后校验文件大小和 SHA-256，并采用临时目录安装；上一版本会保留用于回滚。
