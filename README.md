# 金融、会计与案例知识库 Android 联网同步版

本仓库为金融监管、会计制度与案例查询 APP 提供在线更新服务。

- 制度库：人民银行、国家金融监督管理总局和国家外汇管理局，共 2,021 篇。
- 会计制度库：会计、审计、证券、内控、评估，并接入财政部会计司官方发布渠道。
- 案例库：财政部、证监会、审计署、中央纪委国家监委，数量以服务器最新清单为准。
- `android-app/`：原生 Android APP，首次启动联网下载知识库，启动时及联网后台每天自动检查更新。
- `.github/workflows/automatic-knowledge-update.yml`：服务器端自动采集、校验、发布和切换更新清单。

服务器每天北京时间 04:20 检查财政部、证监会和中央纪委国家监委案例，并检查财政部会计司“政策发布、工作通知、政策解读”官方渠道；财政部详情只抓取新增或目录元数据有变化的内容，证监会核对最新 250 条并复用历史记录，纪检监察只打开新 URL 的详情。会计司新发布正文及可读取的 PDF 附件文本会进入统一检索。每周日同一时段执行证监会全目录核对，并追加金融制度、MaoDocs 会计资料和审计署完整检查。只有知识库指纹发生变化才发布新版本，官网返回数量异常时停止发布并保留上一版本。
- `deployment/`：案例刷新、知识库更新包构建、版本清单和发布工具。
- GitHub Releases：存放知识库压缩包与可安装 APK。

服务器每次发布“上一版本 → 新版本”的差分 ZIP，APP 只下载新增和改变的文件并处理删除清单；每个文件及差分包本身都进行 SHA-256 校验，随后用临时快照原子切换。首次安装、跨版本更新或差分失败时自动回退完整包，上一版本仍保留用于回滚。完整离线 APK 始终包含该版本的全部知识库。

需要只发布新版 APP 或更新机制、而官网暂时限流时，可手动选择 `current` 范围：它从服务器已验证的上一版源状态重新构建并发布，不访问外部资料来源，也不会丢失现有制度或案例。

需要单独检查财政部会计司时，可手动选择 `accounting` 范围；该模式只增量获取会计司新内容，并复用服务器已有的金融制度和案例库。
